\doxysubsection{Подробное описание}
Точка входа сервера обработки векторов 

Сетевой сервер с подсистемой аутентификации SHA-\/224. Принимает подключения клиентов, выполняет аутентификацию и вычисляет сумму векторов uint32\+\_\+t. Все ошибки логируются в файл журнала, а критические выводятся в стандартный поток ошибок. \begin{DoxyWarning}{Предупреждения}
Требуется обязательный параметр --run для запуска сервера 
\end{DoxyWarning}
